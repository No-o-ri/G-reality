G-reality for Windows (local companion)

The companion runs the world server on your PC (127.0.0.1 only) and opens
G-reality in your browser. It generates worlds from a description, keeps every
change in your own PostgreSQL (Neon) database, and runs the world simulation.
No account with us; no keys or database credentials are included in this ZIP.

WHAT YOU NEED
- Windows 10 or 11 and a WebGL2 browser (Chrome, Edge or Firefox).
- A PostgreSQL database URL. A free Neon project works:
  https://neon.tech -> New project -> Connect -> copy the connection string.
- Optional: a Gemini API key (https://aistudio.google.com/apikey). Without it,
  worlds are still generated by the built-in keyword interpreter, which follows
  descriptions less closely.
- Python 3.12+. If it is missing, the launcher offers to install the official
  python.org build with winget (per user, no administrator rights).
- Internet access on first launch (runtime packages are downloaded once).

START
1. Unzip the whole folder (do not run it from inside the ZIP).
2. Double-click G-reality.cmd.
3. First launch only: paste your DATABASE_URL and, optionally, a Gemini key
   when asked (input is hidden). They are saved to
   %APPDATA%\G-reality\.env.local. The database tables are created
   automatically, and runtime packages are installed in %LOCALAPPDATA%\G-reality
   (about a minute).
4. The browser opens when the server is ready. Stop with Ctrl+C or by closing
   the launcher window.

SMART APP CONTROL: G-reality is not code-signed. If Smart App Control is on,
Windows blocks G-reality.cmd ("files of this type from the internet can be
dangerous"). Do not turn Smart App Control off. Instead, install with pip into
a private environment, in PowerShell:
  py -3 -m venv "$env:LOCALAPPDATA\G-reality\env"
  & "$env:LOCALAPPDATA\G-reality\env\Scripts\python.exe" -m pip install --only-binary=:all: "https://github.com/No-o-ri/G-reality/releases/download/v1.1.0/greality-1.1.0-py3-none-any.whl"
  & "$env:LOCALAPPDATA\G-reality\env\Scripts\python.exe" -m greality --shortcut
  & "$env:LOCALAPPDATA\G-reality\env\Scripts\python.exe" -m greality
Full guide: https://github.com/No-o-ri/G-reality/blob/main/docs/INSTALL.md
If only SmartScreen warns, choose "More info" -> "Run anyway": it is a two-line script that starts launcher\launch.ps1.

WHAT NEEDS WHAT
- Read-only sample world: nothing (also on the public website).
- Generate worlds, interact, persistent changes: this companion + database.
- Faithful language-to-geometry design: also a Gemini key.
- Gaussian far field (experimental): WSL2 + a CUDA PyTorch environment;
  never required. Set GREALITY_WSL_DISTRO and GREALITY_GPU_VENV in .env.local.

CONTROLS
Click to look - WASD move - Shift sprint - Space jump / swim up - E interact -
R other actions - T create something in the world (needs a Gemini key) -
Esc release the mouse - ` developer tools (F3 diagnostics).

TROUBLESHOOTING
- Port in use: close the other instance, or run  G-reality.cmd -Port 8770
- Check requirements without starting:  G-reality.cmd -PreflightOnly
- Use a different settings file:  G-reality.cmd -EnvFile "C:\path\to\file"
- Change your database or key: edit or delete %APPDATA%\G-reality\.env.local
  (a .env.local next to G-reality.cmd takes precedence).
- Database unavailable: check the Neon URL and your network connection.
- Smart App Control: the launcher uses only signed Python and pip wheels;
  do not disable Smart App Control.
- Logs: %LOCALAPPDATA%\G-reality\logs\launcher-<timestamp>.log
